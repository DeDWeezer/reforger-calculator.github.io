How it works

  • Firing tables: elevations and flight times are the game's own ballistic tables for every shell and charge (vanilla, current with game 1.8). On level ground, every table row comes out exactly as the game lists it.
  • Height difference: when the target is higher or lower than the mortar, the calculator flies a simulated shell with a drag model fitted to those tables (it reproduces every row within about 3 m). This is more accurate than the "dElev" shortcut many calculators use, which can be off by 5 or more mils at short range.
  • Altitude matters most at long range on a given charge. Read heights from the map contours as carefully as you can.
  • Mils: the M252 sight uses 6400 mils per circle, the 2B14 uses 6000. Azimuth is shown in the right system for the mortar you pick.
  • Shells scatter a little on every shot, so use Adjust fire to walk rounds onto the target. If a game update changes ballistics, compare a few values with the in-game Ballistic Table.
